2. What is Nginx, and what does it do on this server?

Nginx is a web server and reverse proxy. On this server, it is the thing that listens to incoming requests on port 80 and then hands back the HTML files sitting in /var/www/html. When someone types my IP into the browser, Nginx is what answers and shows them this page. In this assignment, it is taking the HTTP request and returning static content.

3. Which commands did I use

I used various commands to get this site up and running.

  • Install: sudo apt update && sudo apt install nginx -y
  • Check status: sudo systemctl status nginx
  • Enable on boot: sudo systemctl enable nginx
  • Reboot system: sudo reboot

We use sudo to run the command as administrator, as installing software can require elevated privileges. The part apt update refreshes the local package index from the repositories but this part doesn't update anything. It simply lets apt know if there are newer versions available. If we skip this part, we might end up installing outdated or missing packages. Then we install the packages we need along with their dependencies with apt install package_name and the -y flag at the end automatically confirms the installation.

Then, when checking the status, we call systemctl which is the system that manages services on modern Ubuntu. Writing status nginx will show if the Nginx service is running. We want to find the line Active: active (running) in the results on the terminal.

To enable this service to run on boot, we use the enable keyword and invoke the systemctl. This won't start the service immediately, but since our installation also started it, I don't need to worry about rebooting to enable it separately.

Additional commands I used were: sudo nano /var/www/html/index.html to edit this page, and lsb_release -a to double check which version of Ubuntu I was running specifically.
